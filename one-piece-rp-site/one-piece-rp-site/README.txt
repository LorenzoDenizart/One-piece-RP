ONE PIECE RP — SUR NANOS

Fichiers :
- index.html : structure et contenu du site
- style.css : design responsive (ordinateur, tablette et mobile)

APERÇU LOCAL
1. Décompressez le dossier si nécessaire.
2. Ouvrez index.html dans votre navigateur.

PERSONNALISATIONS À FAIRE AVANT PUBLICATION
1. Dans index.html, remplacez https://discord.com/ par le lien d'invitation officiel de votre serveur.
2. Remplacez les deux images d'ambiance Unsplash dans style.css par vos propres visuels si vous en avez.
3. Vérifiez les noms, systèmes, règles et informations du serveur avant de rendre le site public.

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Créez un compte sur https://github.com/.
2. Créez un dépôt public, par exemple one-piece-rp.
3. Envoyez index.html, style.css et README.txt à la racine du dépôt.
4. Ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez Deploy from a branch, puis main et /(root), et sauvegardez.
6. Après le déploiement, GitHub affichera l'adresse publique du site.

Le site est une première version vitrine en une seule page. Les liens de navigation pointent vers les sections de cette page.
